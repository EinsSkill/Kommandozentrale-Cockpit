# Releasecheckliste

- [ ] Scope und betroffene Source-of-Truth-Bereiche sind klar.
- [ ] Keine echten persönlichen Daten oder Geheimnisse im Diff.
- [ ] `npm test` erfolgreich.
- [ ] `getMailV3()` verwendet weiterhin `OPS.EMAIL_REFS`.
- [ ] Frontend-Datenformat bleibt kompatibel oder ist dokumentiert angepasst.
- [ ] Fehlerpfade und fehlende Daten bleiben sichtbar.
- [ ] Unabhängiger Review abgeschlossen.
- [ ] Nutzerfreigabe für Merge und Live-Deployment vorhanden.
- [ ] Live-Smoke-Test durchgeführt.
- [ ] OPS Audit-Log aktualisiert.
